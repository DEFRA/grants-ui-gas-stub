# grants-ui-gas-stub

This repository provides a stub of [fg-gas-backend](https://github.com/DEFRA/fg-gas-backend) (GAS) for testing [grants-ui](https://github.com/DEFRA/grants-ui) where integration is not appropriate.
  
## Usage
The deployed service stands up an instance of [MockServer](https://www.mock-server.com) with a set of URLs defined in the [expectations.json](expectations.json) file.
